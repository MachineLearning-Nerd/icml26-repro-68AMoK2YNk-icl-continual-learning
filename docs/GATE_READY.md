# Evidence-release checklist

- [x] Paper title, authors, arXiv, and OpenReview identifiers are documented.
- [x] Every theorem claim has a producer, output, finite scope, and limitation.
- [x] Claims 1–4 have generated JSON evidence from the fixed CPU harness.
- [x] C5a and C5b report-only/partial artifact boundaries are explicit.
- [x] Source tree and source hash are recorded; missing tar is disclosed.
- [x] Citation and author thank-you note are present.
- [x] Branch purposes and old-to-new names are documented.
- [x] The old external score is separated from the local evidence gate.
- [x] The three canonical gate JSON files are generated identically.
